Sum up 19 November's world news in one image. One 1024x1024 PNG summarising Thursday 19 November 2026 in six panels: the US-China-Russia summit in Shenzhen, the Iran war escalation in the Strait of Hormuz, Ukraine's strike on the Kerch Bridge, the Riyadh tower attack and Gaza operation, the UN court ruling on Myanmar, and the GTA VI launch.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the pre-built
`entry.png` to `/output/entry.png`. No network, no randomness — two runs
write identical bytes. Build the image from source with
`python3 build_image.py`.
